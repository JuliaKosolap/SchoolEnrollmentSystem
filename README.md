# School Enrollment System

Course project developed in C++.

## Description

Information system for managing the school enrollment process.

### Features

- Application submission
- Document verification
- Application approval/rejection
- Student distribution among classes
- Final approval of enrollment lists

## Technologies

- C++
- Object-Oriented Programming
- UML
- Visual Studio 2022

## OOP Principles

- Encapsulation
- Inheritance
- Polymorphism
